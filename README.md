ACE3 ballistics compatibility for the mod AMF All In One: [Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=1781990846)
- Can be played without ACE3.
- If ACE3 Advanced Ballistics option enabled, possibility to select SCROME J8 and J10 gyroscopic compensation reticles with Zoom In/Out (+/- as default).
- Default ballistic muzzle velocities according to Advanced Ballistics ICAO muzzle velocities (15°C, 1013.25 hPa, 0%).
- Default ballistic airFriction based on Advanced Ballistics ICAO ballistic coefficients and drag models with the [ACE3 tool by Ruthberg](https://github.com/acemod/ACE3/blob/master/tools/generate_airfriction_config.py).
- ACE3 "mass" according to manufacturers weapons and scopes data.
- "mass" magazines according to vanilla Arma 3 values.
- "ACE_ScopeHeightAboveRail" and "ACE_railHeightAboveBore" values with ACE3 "checkScopes.sqf".
- CBA Weapons Options (OPTIONS - ADDONS OPTIONS) with bolt action rifles.
- Cartridge ejection effect added with bolt action rifles.
- Accurate reticles and mRad calibration for Schmidt & Bender and Scrome riflescopes.
- AtragMx presets for J8 and J10 gyroscopic compensation reticles.
- Effects and terminal ballistic based on vanilla Arma 3 values.

- Military SCROME J10 BDC reticle compatibility with PGM Hecate II and 12.7x99 FMJ, AP, API, APEI: zeroing in-game 1300m.
- Military SCROME J8 BDC reticle compatibility with FRF2 and 7.62x51 AP: zeroing in-game 100m.
- Military SCROME J4 BDC reticle compatibility with 5.56 rifles: zeroing in-game 300m.
- Military SCROME J8 and J10 MilDot reticles: zeroing in-game 100m.
- ELCAN SpecterDR 1x/4x 5.56 reticle according to manufacturer data (calibration M855 62gr 16" barrel): zeroing in-game 100m.
- ELCAN SpecterDR 1x/4x 7.62 reticle according to manufacturer data (calibration M80 147gr 20" barrel): zeroing in-game 100m.
